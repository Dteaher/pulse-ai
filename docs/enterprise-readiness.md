# Готовность к B2B

## Уже есть

- Типизированная модель, ограниченная коррекция LLM и смена provider через конфигурацию.
- Graph/semantic/XML/XSD/DI validation для документированного subset.
- Preview перед Apply, история и Undo в текущей вкладке.
- Общий код доступа для демо: Authorization header, сравнение в постоянном времени. Код хранится в памяти вкладки, не в localStorage.
- Production не запускается без `PULSE_ACCESS_TOKEN`. TLS и изоляция backend предусмотрены Compose/Caddy.
- Ограничение body до 2 MB, одновременных дорогих операций, операций в минуту/24 часа. Квоты считаются до dispatch, включая неуспешные запросы и cache hits.
- Ключи только на backend; production raw debug выключен. Ответы и журналы ошибок не должны содержать traceback или секреты.
- Lockfiles, mock-тесты, проверки сборки и зависимостей в CI.

## Ограничения защиты демо

Код workspace — единый общий секрет, не пользовательская авторизация. Квоты действуют на один backend-процесс и сбрасываются при рестарте. Нельзя рассчитывать на них при нескольких workers/репликах. Лимит операций не является гарантированным денежным cap: анализ, repair, аудит и fallback могут делать несколько LLM-вызовов. Настройте бюджет у provider, token/deadline/retry limits и наблюдение за расходами.

API docs/health/examples и безопасный provider info доступны без кода. POST process endpoints защищены кодом. X-Pulse-Session используется для cache scope, не для контроля прав.

## До полноценного SaaS

1. Идентичность пользователей, SSO, роли и tenant isolation; серверное хранилище и восстановление.
2. Общие persistent квоты и учёт затрат на уровне пользователя/организации; мониторинг и алерты.
3. Политика обработки документов: согласованные провайдеры, размещение, retention, удаление, аудит доступа и резервные копии.
4. Испытания нагрузки, threat model, security review, политика обновлений, SLO и эксплуатационные runbooks.
5. Юридические условия пилота, лицензия, сопровождение и оценка качества на данных заказчика.

XSD/программные проверки не гарантируют соответствие бизнес-правилам. Требуется review аналитика. Система не выполняет BPMN процессы и не управляет промышленным оборудованием. Сертификаций и подтверждённых внедрений нет.
