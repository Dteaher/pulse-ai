# Fable 5.1: явная схема только для резерва

Реальные запросы MultiAI `claude-fable-5-1` через LLMRouter, принудительный тестовый timeout Polza. `FALLBACK_LLM_SCHEMA_IN_PROMPT=true`, reasoning low, cache off, без output token cap, без изменения рабочего .env. Основной провайдер не получает схему в промпте. Три генерации, 6 реальных POST; Polza не вызывалась по сети. Цены MultiAI в рублях неизвестны.

| Сценарий | Время | Результат |
|---|---:|---|
| SIMPLE | 17,45 с | BPMN; семантические проверки passed |
| MEDIUM | 57,36 с | BPMN; семантические проверки passed |
| COMPLEX | 86,61 с | Валидная ProcessDefinition, лишний критичный Clarify; без BPMN |

SIMPLE: действия, роль, XOR, два завершения, XML fidelity. MEDIUM: роли, XOR, цикл документов, event wait, четыре MessageFlow, XML fidelity. Обе схемы импортированы в bpmn-js в Edge, все узлы отображаются, ошибок страницы нет, резерв показан в интерфейсе: 2 browser tests passed.

В COMPLEX модель спрашивает о конечном отказе согласования договора, хотя golden text задаёт цикл доработки с возвратом к проверке. Это избыточное критичное уточнение модели. Оно не удалялось автоматически: Clarify корректно остановил генерацию. XSD/layout для COMPLEX не выполнялись. Полный успех на трёх сценариях не подтверждён.

Вывод: явная схема исправила наблюдавшуюся несовместимость JSON для этой выборки, но не устранила все семантические ошибки модели. Производственная конфигурация не изменена.
