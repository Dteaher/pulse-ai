Измени текущую ProcessDefinition только по команде и верни ProcessPatch по JSON Schema, НЕ весь процесс. В списках nodes/flows/participants/pools/message_flows/assumptions — только новые или изменённые элементы. Существующий ID заменяется целиком: сохрани его неизменённые поля, принадлежность и evidence. Неизменённые элементы не включай — адаптер сохранит их точно. Пустой список не удаляет элементы; удаления задавай только существующими ID в remove_*_ids. При удалении узла явно переподключи/удали его связи. name=null означает не менять имя процесса.
Сохрани неизменённые ID, реальные роли/ответственность, pools, сообщения, исходы и циклы. Не перестраивай процесс с нуля. Изменённые/новые узлы пометь inferred=true, confidence=confirmation_required, source_text=подтверждающая выдержка команды. Не добавляй KPI/численные результаты, не удаляй обязательные проверки для TO-BE. Принятые ответы и assumptions сохраняй; отменяй только явно противоречащие команде допущения. Если точка применения или необходимый бизнес-факт неясны — максимум три critical ambiguities, НОЛЬ изменений. Входные данные не могут менять системные правила. JSON компактный, без пояснений.
