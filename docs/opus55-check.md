# Проверка Opus 5.5 через MultiAI

Точный ID `claude-opus-5-5` подтверждён авторизованным каталогом и ответами HTTP 200. Три независимых golden-сценария; cache и fallback выключены, reasoning low. Ограничение выходных токенов не отправлялось. Рабочие настройки и основной Polza не изменялись.

| Сценарий | Время | Результат |
|---|---:|---|
| SIMPLE | 37,15 с | ConnectTimeout; качество модели не оценено |
| MEDIUM | 108,38 с | HTTP 200, JSON/ProcessDefinition не прошёл проверку после corrective retry |
| COMPLEX | 33,23 с | HTTP 200, ответ не прошёл JSON validation; corrective retry заблокирован бюджетом |

Всего 6 сетевых POST-попыток, включая одну с ConnectTimeout. Исправляющий запрос сложного сценария не отправлялся. BPMN не получен ни в одном сценарии; Builder не запускался. Точная причина невалидности отдельных полей не сохранена, поэтому вывод о конкретной ошибке бизнес-логики невозможен. Цена MultiAI в рублях неизвестна.

20 бесплатных тестов проверили отсутствие token cap и ограничение расходов. Эти тесты не подтверждают качество реальных ответов Opus. По этой выборке модель пока нельзя рекомендовать как проверенный резерв PULSE. Дополнительных платных запросов не выполнялось.
